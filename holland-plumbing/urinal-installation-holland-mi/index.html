    Commercial Urinal Installation in Holland

    Offices and restaurants want urinals that survive heavy use. We set vitreous china units on floor-mounted carriers, connect them with new outlet gaskets and stainless bolts, and pair them with a Sloan or Zurn flush valve sized to the bowl. We check partition spacing too. Most codes want 15 inches from centerline to the side.

    Sloan Flush Valve Installation in Holland, MI

    Sloan Royal valves are on most commercial urinals we see. Each Sloan Royal gets the right inside parts for the bowl, a tuned control stop and a rebuild kit on hand. Sensor versions mount the same way. Battery models need no wiring.

    ADA Urinal Installation in Holland

    Accessible urinals start at the carrier. We set the carrier so the finished rim lands at 17 inches or lower, keep the clear floor space free of partitions and door swings, and mount the flush handle or sensor where a seated user can reach it. We measure the rim twice. Inspectors measure too.

    Old Urinal Removal and Replacement in Holland

    Old urinals come off harder than they went on. Rusted bolts and seized valves often have to be cut, so we protect the tile while working. We never reuse the old gasket. The flange gets cleaned to bare metal.

    Waterless Urinal Upgrades in Holland

    Switching to waterless is mostly a fixture swap. We remove the flush valve, cap the supply and set the waterless bowl on the same carrier. Many jurisdictions want a capped supply kept for later. That allows a future change back.

    Urinal Rough-In for New Restrooms in Holland

    Tenant improvements need rough-in before the walls close. We lay out each urinal at 30 inches center to center and 15 inches from the side wall, set the carriers, and run waste, vent and supply so the finish crew can hang fixtures as soon as tile is done. We stay in touch with the GC daily. Rough inspection comes first.

    Rough-In Plumbing for Urinals in Holland, MI

    Rough-in decides whether the finish goes smoothly. We set the carrier, run a 2 inch waste line to the outlet height on the spec sheet, stub the 3/4 inch supply where the flush valve will land, and tie the vent in before anyone hangs drywall. Inspectors see it open. Then the walls close.

    Home Gym and Garage Urinals in Holland, MI

    A garage urinal saves tracking dirt into the house. We run the drain to the nearest stack or building drain, add a vent or an air admittance valve where local code allows one, and pick a compact bowl that fits the space without a full commercial carrier. Unheated garages need freeze planning. Ask us about the layout.
