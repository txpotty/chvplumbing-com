    Wall-Hung Toilet Installation in Flint, MI

    Wall-hung toilets mount to a steel carrier inside the wall, with the tank hidden behind an access plate. We install Geberit, Grohe and Kohler carrier systems and set the bowl height to your preference. This work is easiest during a remodel when the wall is open.

    Pressure-Assisted Toilet Installation in Flint
